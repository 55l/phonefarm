# Getting started

For this customized Instagram workspace, follow **[AI_SETUP.md](../AI_SETUP.md)** from start to finish. It covers host prerequisites, the dedicated database, exact driver/WDA preparation, phone trust/signing, manual Instagram control, and a shared-password temporary website.

The original standalone scheduler/plugin architecture remains available for development, but its legacy TikTok setup is not the default workflow. Do not start the worker or enable TikTok as an incidental part of the Instagram manual-control demo.
